# The gadget shelf

A Listening Shelf-style library of eight useful-product candidates. Brand facts, independent owner reports and hands-on editorial evidence are separated. Agaro Supreme is explicitly an evidence-gap investigation, not an endorsed recommendation.

No checkout, accounts, tracking, public submissions, affiliate links or private purchase data. Saved marks and private notes use localStorage on the current browser only. Research snapshot: 5 November 2026. No live prices, stock or deal claims. International manufacturer references do not establish Indian availability or warranty.

Product images originate from each linked manufacturer page and identify the exact model. Names and images remain their respective owners' property. See each card's evidence disclosure for source URLs, dates, model-specific limits and uncertainties.

Run as a static site. No build or runtime dependencies except Google Fonts. Open index.html via any static HTTP server.

## Source and UI qualification

Local Chromium exercised at 320, 390, 820 (reduced motion), and 1280 widths: all eight photos decode, no horizontal overflow, search/empty/reset, brand filter, evidence disclosure, literal private-note persistence, save/reload/unsave/saved-filter and malformed storage recovery passed. These are software-browser checks, not physical-phone tests. No claims of hands-on product testing by this shelf.
